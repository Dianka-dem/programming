# Отчёт по лабораторной работе: Многопоточное программирование на C (pthreads)

## Описание работы

В данной лабораторной работе были реализованы 7 заданий, демонстрирующих различные аспекты многопоточного программирования с использованием библиотеки **pthreads** в языке C.

---

## Задание 1: Параллельное выполнение потоков

**Описание:** Дочерний и родительский потоки выполняются параллельно, выводя числа от 1 до 5.

**Особенности:** Порядок вывода не гарантирован из-за параллельного выполнения.

---

## Задание 2: Последовательное выполнение потоков

**Описание:** Сначала полностью выполняется дочерний поток, затем родительский.

**Особенности:** Использование `pthread_join()` для ожидания завершения дочернего потока.

---

## Задание 3: Вывод строк из нескольких потоков

**Описание:** 4 потока одновременно выводят свои наборы строк.

**Особенности:** Каждый поток получает свой массив строк через аргумент.

---

## Задание 4: Параллельный вывод с задержкой

**Описание:** 4 потока выводят строки с задержкой 1 секунда.

**Особенности:** Потоки работают полностью независимо.

---

## Задание 5: Обработчик очистки

**Описание:** Добавлен обработчик `cleanup_handler`, который вызывается при завершении потока.

**Особенности:** Использование `pthread_cleanup_push()` и `pthread_cleanup_pop()`.

---

## Задание 6: Sleep Sort (сортировка сном)

- Создаётся отдельный поток для каждого элемента массива.
