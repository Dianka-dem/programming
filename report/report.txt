Расчётно-графическая работа по дисциплине «Информационные технологии» на тему:
«Разработка веб-платформы для потокового видео Videohub»

Выполнила: Студент группы ИКС-531 Еремеева Д.С.
Проверил: Старший преподаватель Андреев А.В.

Новосибирск, 2026

Цель работы: создать функциональную веб-платформу для потокового видео.

Постановка задачи: разработать видеоплатформу с регистрацией и авторизацией (JWT-токены), загрузкой видео на сервер, потоковым воспроизведением, списком видео на главной странице.

Используемые технологии:
- Бэкенд: Python 3.12, Django 6.0.5, Django REST Framework, JWT, SQLite
- Фронтенд: React 19, React Router DOM, Axios, Framer Motion, React Icons
- Дизайн: Figma (голубая тема)

Архитектура проекта: клиент-серверная (React → Django API → SQLite).

API эндпоинты:
- POST /api/auth/register/ – регистрация
- POST /api/auth/login/ – вход (JWT)
- GET /api/content/ – список видео
- POST /api/content/upload/ – загрузка видео
- GET /api/content/{id}/stream/ – потоковое видео

Скриншоты страниц прилагаются отдельными файлами.

Трудности и их решение:
1. Потоковое воспроизведение – реализована поддержка HTTP Range запросов.
2. JWT авторизация – добавлен interceptor в axios.
3. CORS ошибки – установлен django-cors-headers.
4. Миграции БД – полная очистка и повторное применение миграций.

Результаты работы: полноценная видеоплатформа Videohub с регистрацией, загрузкой и просмотром видео, адаптивным дизайном и анимациями.
